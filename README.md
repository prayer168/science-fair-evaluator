# Science Fair Evaluator

`science-fair-evaluator` 是一個給 Codex 使用的國小科展評估與前置報告產生技能包。當使用者提供資料、文章、影片、圖片、表格、觀察紀錄、學生想法或任何檔案時，這個 Skill 會先評估題材是否適合發展成科展，再查找國內外相似研究，判斷創新性、可執行性、安全性、資料品質與獲獎潛力，最後推薦一個最值得發展的題目，並產出仿科展作品書格式的前置作業報告書。

目前版本：`0.6.0`

## 主要用途

- 從檔案、資料、文章或生活觀察中找出科展題目
- 在題目確定前搜尋國內外相似實驗與科展作品
- 評估候選題目的創新性、可執行性、安全性與獲獎潛力
- 推薦一個最佳題目，而不是同時發展多個分散題目
- 將題目轉換成研究目的、研究架構、子實驗與資料分析計畫
- 產出「國小科學展覽前置作業報告書」
- 強制將「參考文獻」整理為 APA 格式

## 核心流程

完整流程預設包含：

1. 題材轉換
2. 相似研究搜尋
3. 相似研究比較表
4. 創新性、可執行性與獲獎潛力評估
5. 最佳題目推薦
6. 初步建議
7. 科學原理
8. 文獻與公開知識回顧
9. 既有科展比較
10. 新穎性判斷
11. 研究缺口
12. 科展性評估
13. 學生適切性
14. 安全與倫理
15. 競爭力估計
16. 研究問題與研究目的
17. 變因、測量、材料與資料分析設計
18. 失敗模式與備案
19. 國小科學展覽前置作業報告書

## 題目制定規則

在正式產出題目前，技能必須先搜尋國內外相似資料，例如：

- 臺灣歷屆科展作品或地方科展 PDF
- 國外學校或大學的教學示範
- 學術論文、技術文獻或工程應用資料
- 官方安全資料、產品規格或科學教育資源

接著比較：

- 別人已經做過什麼
- 與本題重疊程度
- 還有什麼變因、方法或情境沒被充分探討
- 是否適合國小學生操作
- 是否安全
- 是否有足夠資料品質與科展競爭力

最後只推薦一個最好的題目，並以該題目跑完整報告流程。

## 前置作業報告書格式

輸出會仿照科展作品書格式，至少包含：

1. 封面資訊
2. 摘要
3. 壹、參考題目
4. 貳、研究背景與動機
5. 參、研究目的
6. 肆、研究架構
7. 伍、材料設備
8. 陸、研究過程與方法
9. 柒、資料分析
10. 捌、材料、工具、設備的取得或製作方式
11. 玖、安全、倫理與風險控管
12. 拾、預期結果與討論方向
13. 拾壹、可行性與時程規劃
14. 拾貳、失敗模式與備案
15. 拾參、科展亮點與加強方向
16. 拾肆、參考文獻
17. 拾伍、下一步行動

## 研究背景與動機

「研究背景與動機」必須：

- 以繁體中文撰寫
- 500-1000 字
- 先做文獻回顧
- 內文使用作者與年代引用
- 連結生活情境、科學原理、既有研究、研究缺口與國小可行性

範例：

```text
Revie 與 Uhlig（2008）指出，水溶液中的離子會影響金屬腐蝕速率。
```

```text
工程上常以犧牲陽極降低鋼鐵腐蝕（Jones, 1996）。
```

## 研究目的與子實驗

「陸、研究過程與方法」必須直接對應「參、研究目的」。

每個研究目的若科學上可行，至少產生 2-3 個子實驗，並且跨全報告連續編號：

```text
研究目的一 -> 實驗 1、實驗 2、實驗 3
研究目的二 -> 實驗 4、實驗 5、實驗 6
```

每個實驗都必須包含：

- 實驗目的
- 操縱變因、應變變因、控制變因
- 對照組、實驗組
- 實驗時間
- 詳細步驟
- 實驗紀錄表格
- 建議圖表
- 可能誤差與控制方式
- 安全注意事項

重點：不能只輸出變因表格。每個實驗都必須有可操作的詳細步驟。

## 材料與安全

「材料、工具、設備的取得或製作方式」需要寫得具體，例如：

- 可能購買地點
- 網路搜尋關鍵字
- 學校或家庭可取得來源
- 規格、數量與替代品
- 成人協助項目
- 校正、標籤、保存與廢棄方式

「安全、倫理與風險控管」需要包含：

- 風險來源
- 可能事故
- 嚴重程度
- 預防方式
- 防護用品
- 成人專責步驟
- 緊急處理方式
- 廢棄物處理
- 較安全替代方案

## 參考文獻規則

最後章節標題必須是：

```text
參考文獻
```

不可使用：

- 參考來源
- 參考資料
- 來源
- 單純連結清單

每一筆都必須整理成 APA 7 風格。若有可取得連結，連結應放在 APA 條目中。

範例：

```text
American Galvanizers Association. (n.d.). Sacrificial anodes. https://galvanizeit.org/corrosion/corrosion-protection/sacrificial-anodes
```

```text
Revie, R. W., & Uhlig, H. H. (2008). Corrosion and corrosion control: An introduction to corrosion science and engineering (4th ed.). Wiley.
```

## 使用方式

將這個資料夾放入 Codex 的 skills 目錄，例如：

```text
C:\Users\<your-name>\.codex\skills\science-fair-evaluator
```

在 Codex 中可以用類似以下方式呼叫：

```text
[$science-fair-evaluator](C:\Users\<your-name>\.codex\skills\science-fair-evaluator\SKILL.md) 鎂棒
```

或直接描述需求：

```text
請用 science-fair-evaluator 評估「不同水質下鎂棒保護鐵釘」，先搜尋國內外相似研究，再推薦最佳題目並產出前置作業報告書。
```

## 輸入資料類型

這個 Skill 可用於：

- 研究想法或題目草稿
- 學生觀察紀錄
- 實驗資料或試算表
- 文章、新聞、論文、網站內容
- 圖片、影片或影片逐字稿
- 學校、社區或生活中的問題情境
- 歷屆科展作品或相近研究

若素材涉及最新研究、歷屆科展紀錄、產品規格、安全規範、APA 格式或科展規則，Codex 應上網查證，避免用過時資訊。

## 設計原則

這個技能包的核心原則是：**小而嚴謹，比大而模糊更適合國小科展。**

一個好的國小科展題目應該能清楚回答：

- 我想知道什麼？
- 前人做過什麼？
- 我的題目新在哪裡？
- 我改變了什麼？
- 我量到了什麼？
- 我怎麼確定比較公平？
- 我的結果可以用什麼圖表說明？
- 如果結果不如預期，還能學到什麼？

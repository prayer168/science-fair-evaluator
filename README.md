# Science Fair Evaluator

`science-fair-evaluator` 是一個給 Codex 使用的科展評估技能包。當使用者提供資料、文章、影片、圖片、表格、觀察紀錄、學生想法或任何檔案時，這個 Skill 會協助判斷它是否適合發展成科展題目，並進一步推薦可行、有探究精神、具創新性的研究方向。

這個技能包特別偏向國小科展情境：重視學生能不能親自操作、能不能量測、是否安全、是否能做出公平比較，以及是否能從普通生活現象發展出真正的科學探究。

## 主要用途

- 從檔案、資料或文章中找出適合的科展題目
- 評估一個科展想法的可行性、創新性與獲獎潛力
- 判斷題目是否過度重複歷屆科展或常見實驗
- 協助把模糊想法改寫成可研究的問題
- 設計研究目的、實驗架構、量測方法與資料分析方式
- 檢查國小學生操作的適切性、安全性、倫理與設備限制
- 提供題目升級方向、風險備案與下一步建議

## 評估內容

完整科展評估預設包含：

1. 題目理解與重新定義
2. 初步結論
3. 科學原理
4. 國內外研究現況
5. 歷屆科展與相近研究
6. 重複性與創新性判斷
7. 研究缺口
8. 科展精神與探究成熟度
9. 創新性
10. 國小適切性
11. 安全、倫理與設備限制
12. 獲獎潛力分析
13. 題目升級方向
14. 建議題目名稱
15. 建議研究問題
16. 建議研究目的
17. 建議實驗架構
18. 建議量測方法
19. 所需要的材料與工具
20. 建議資料分析
21. 風險與備案
22. 最終建議

此外，技能包也會視情況補充資料品質、變因可操作性、時間與成本、評審溝通力、地方生活連結，以及失敗後可學習性等面向。

## 使用方式

將這個資料夾放入 Codex 的 skills 目錄，例如：

```text
C:\Users\<your-name>\.codex\skills\science-fair-evaluator
```

之後在 Codex 中可以用類似以下的方式呼叫：

```text
Use $science-fair-evaluator to evaluate this file and recommend science fair topics.
```

或直接用中文描述需求：

```text
請用 science-fair-evaluator 評估這篇文章能不能發展成國小科展題目，並推薦 3 個研究方向。
```

```text
我有一份植物生長觀察資料，請幫我判斷科展潛力、創新性、研究缺口與實驗架構。
```

```text
這個學生想做「不同水質對豆芽生長的影響」，請幫我評估是否太常見，並提出升級版題目。
```

## 輸入資料類型

這個 Skill 可用於評估多種素材：

- 研究想法或題目草稿
- 學生觀察紀錄
- 實驗資料或試算表
- 文章、新聞、論文、網站內容
- 圖片、影片或影片逐字稿
- 學校、社區或生活中的問題情境
- 歷屆科展作品或相近研究

如果素材涉及最新研究、歷屆科展紀錄、產品規格、安全規範或政策資訊，Codex 應視情況上網查證，避免用過時資訊做判斷。

## 輸出特色

評估結果會盡量做到：

- 以繁體中文輸出
- 直接指出是否值得發展
- 區分「常見題目」與「可升級題目」
- 把題目轉成可操作的研究問題
- 明確列出變因、控制組、量測方法與資料分析
- 對安全、倫理、設備與時間限制提出替代方案
- 不保證得獎，但會分析競爭力與改進方向

## 檔案結構

```text
science-fair-evaluator/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── evaluation-framework.md
```

- `SKILL.md`: Codex 觸發與執行此技能時讀取的主要流程。
- `agents/openai.yaml`: 技能在介面中的顯示名稱、簡介與預設提示。
- `references/evaluation-framework.md`: 完整評估規準、評分方式與題目升級策略。

## 適合對象

- 國小自然科教師
- 科展指導老師
- 想協助學生找題目的家長
- 需要把生活現象轉成探究題目的學生
- 想快速檢查科展題目可行性的教材設計者

## 設計原則

這個技能包的核心原則是：小而嚴謹，比大而模糊更適合科展。

一個好的國小科展題目不一定要艱深，但應該能清楚回答：

- 我想知道什麼？
- 我改變了什麼？
- 我量到了什麼？
- 我怎麼確定比較公平？
- 我的結果和原本想法有什麼不同？
- 下一次可以怎麼改得更好？

這些問題也是 `science-fair-evaluator` 評估與推薦題目的主要依據。
